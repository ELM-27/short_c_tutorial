# C Language Introduction
## Purpose
The code in this repository was created as a short introduction to the C programming language and taught during a summer internship program for freshman at Samarkand International University of Technology in Samarkand, Uzbekistan over the Summer of 2026.
## Teaching Format
Each lesson starts with a short presentation introducing the current topic to students. After this, the students were given the code for each lesson. The rest of the class was spent going through these sample programs with students. While going through each section, I left ample room for students to ask questions, and I answered them to the best of my ability.
